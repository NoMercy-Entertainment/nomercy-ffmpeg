# Security policy

## Reporting a vulnerability

Please report security vulnerabilities **privately**. Do not open a public issue.

1. Go to the [Security tab](https://github.com/NoMercy-Entertainment/nomercy-ffmpeg/security) of this repository.
2. Choose **Report a vulnerability**.
3. Describe the problem, the affected release and platform, and how to reproduce it.

Only the maintainers see the report. It stays private until a fix is released.

## Supported versions

Only the latest release gets security fixes. Older releases are not patched; update to the latest one.

## Known vulnerabilities without a fix

Some CVEs affect a library version this build uses while the project that owns the code has no fixed release yet. They are listed in [docs/security/known-unfixed.md](docs/security/known-unfixed.md).

More about how releases are protected: [Security](https://github.com/NoMercy-Entertainment/nomercy-ffmpeg/wiki/Security) on the Wiki.
